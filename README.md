# 태권용신 — 열한 빛의 약속

태권도장 TV·빔프로젝터에서 승품심사 합격 결과를 발표하는 로컬 행사 도구입니다.
로그인·서버 없이 한 기기에서 준비하고 발표합니다. 국기원 공식 서비스가 아닙니다.

## 바로 써 보기

**https://moneystar4326-byte.github.io/taekwon-yongsin/**

설치 없이 Edge 또는 Chrome에서 바로 열립니다. TV에 연결한 컴퓨터에서 열고 전체화면으로 진행하세요.
명단·사진은 그 컴퓨터 브라우저에만 저장됩니다(서버로 전송되지 않음).

## 처음 받은 분께

1. [Node.js](https://nodejs.org) 20 이상을 설치합니다.
2. 이 저장소를 내려받은 폴더에서 `npm install` → `npm run build` → `npm run preview`
3. 브라우저(Edge 또는 Chrome)에서 http://localhost:4173 을 엽니다.
4. 처음에는 상단 **연습 모드 → 가상 명단 채우기**로 흐름을 먼저 보세요.

명단·사진·로고는 각자 브라우저에만 저장되며 저장소에는 들어 있지 않습니다.

> **배경 음악 주의**: `public/assets/music/`의 곡은 유튜브 모음에서 잘라 온 저작권 있는 곡입니다. 도장 내부 행사용으로만 쓰고, 행사 영상을 유튜브·SNS에 올릴 때는 `assets-source/music/cc0-web/`의 무료(CC0) 곡으로 바꾸세요(같은 이름으로 덮어쓰고 다시 빌드).

## 실행

```bash
npm install
npm run dev        # 개발 서버 → http://localhost:5173
npm run build      # dist/ 에 배포용 정적 파일 생성
npm run preview    # 빌드 결과 확인 → http://localhost:4173
npm test           # 발표 그룹·상태 전환 단위 테스트
npm run assets     # assets-source/ 원본 → public/assets/ 웹용 변환
```

- 준비 화면: `#/setup`, 행사 진행: `#/ceremony`
- `dist/` 폴더를 아무 정적 서버에 올려도 동작합니다. 브라우저 보안 정책상 `index.html`을 파일로 직접 여는 것보다 `npm run preview` 같은 로컬 서버 사용을 권장합니다.
- 최초 로딩 후 외부 요청이 없습니다. 완전한 오프라인 재실행(서비스 워커)은 아직 지원하지 않습니다.

## 자동 진행과 배경 음악

- **도입부는 자동**: [시작]을 한 번 누르면 손 얹기 → 소환(구호 시간, 기본 10초) → 용신 등장까지 스스로 넘어가 **첫 수련생 사진에서 멈춥니다**.
- **합격 발표는 직접**: 수련생 사진·이름이 크게 나온 상태에서 [합격 발표] → 5·4·3·2·1 → 합격 공개 → [다음 수련생]. 발표 방식 기본값은 "한 명씩"이며 "품별 단체(최대 4명)"도 고를 수 있습니다.
- 배경 음악: 대기 → 서서히 웅장해지는 오케스트라(New Sunrise), 소환·용신 → 시네마틱 합창(Epic Endgame), 발표 준비·카운트다운 → 큰 타악기(Unexplored), 합격 → 승리 테마(Victory), 기념 페이지 → 영웅 테마(JRPG Theme). 합격 곡은 매번 첫 소절부터 바로 터집니다. 대사가 나올 때와 카운트다운 동안은 음악을 낮춥니다. 곡은 모두 CC0이며 출처는 [public/assets/music/CREDITS.txt](public/assets/music/CREDITS.txt)에 있습니다. 같은 이름의 mp3로 바꾸면 다른 곡을 쓸 수 있습니다.

## 행사 당일 순서

1. 준비 화면에서 명단, 사진, 결과(합격/불합격/미정)를 입력하고 `3. 시작 전 점검`을 확인합니다.
2. `행사 진행 화면으로` → 이미지 로딩 확인 → `무대 열기` (이 클릭부터 소리가 켜집니다)
3. 대기 → **시작** → 손 얹기(약 6초 자동) → 소환: 아이들 구호가 끝나면 **다음** → 용신 등장(약 10초 자동) → 발표 준비에서 명단 확인 후 **카운트다운 시작** → 5·4·3·2·1 → 합격 공개 → **다음 발표** … → 기념 페이지
4. 단축키: `Space` 일시정지/재개, `→` 다음, `M` 음소거, `Esc` 전체화면 해제(명단 삭제와 무관)

연습할 때는 상단 `연습 모드`를 쓰세요. 실제 명단과 별도 저장소를 쓰고, 무대에 "연습 모드" 표시가 나옵니다.

## 결정 사항

- **주인공 머리 색은 짙은 갈색**을 기준으로 합니다(기획서의 검정에서 변경, 2026-10-15). 전달받은 장면 12장과 캐릭터 3장이 모두 갈색으로 일관되어 있어 재제작 대신 기획서를 맞췄습니다.
- 카운트다운, 합격, 기념 장면은 숫자·문구·프레임이 박힌 시안을 쓰지 않습니다. 배경 + 투명 용신 + HTML(숫자·사진·이름)로 합성합니다.
- 구슬 11개와 품새 매핑은 [src/domain/orbs.ts](src/domain/orbs.ts)에 있습니다. 상징은 창작 설정입니다.

## 자산 교체 방법

원본은 `assets-source/`에 보존되어 있습니다(파일명 앞 번호 = 전달받은 순서).
`scripts/prepare-assets.mjs`가 웹용 변환본을 만듭니다. 구슬은 원형 마스크로 가장자리를 정리하고, 용신·주인공은 넓은 반투명 광채를 줄입니다.

| 할 일 | 방법 |
|---|---|
| 클린 배경 교체 | `assets-source/clean-day.png`(공개·기념 장면), `clean-summon.png`(발표 준비·카운트다운)를 바꾸고 `npm run assets`. 둘 다 있으면 웹 구슬 11개도 표시합니다 |
| 장면 이미지 교체 | 같은 이름으로 `assets-source/` 원본을 바꾸고 `npm run assets` |
| 여자 주인공 소재 | `public/assets/characters/girl-lookup.webp` 추가 후 [assets-manifest.ts](src/config/assets-manifest.ts)에서 상태를 `needs-review`/`approved`로 변경 |
| 검수 완료 표시 | [assets-manifest.ts](src/config/assets-manifest.ts)의 `status` 를 `approved` 로 |
| 장면 영상(Kling) | [kling-작업/작업표.md](kling-작업/작업표.md)대로 만든 영상을 `kling-작업/2_결과영상여기에/`에 넣고 `npm run videos` → `npm run build`. 없는 장면·재생 실패·효과 줄이기 모드에서는 정지 이미지로 자동 대체 |
| 녹음 음성 | [audio.ts](src/services/audio.ts)의 `VOICE_FILES` 에 대사 id(`idle`, `touch`, `dragon`, `ready`, `complete`) → 파일 경로 |

## 미해결 항목

- 클린 배경 2장(`clean-day.png`, `clean-summon.png`)은 원본 장면에서 아이·구슬·받침대를 로컬 AI(LaMa)로 지운 보정본입니다. 가운데 난간이 매끈하게 바뀌었고 소환 배경에는 빛줄기 일부가 남아 있습니다. 더 좋은 이미지가 생기면 같은 이름으로 교체 후 `npm run assets`
- 여자 주인공 투명 소재 없음 → 여자 선택 시 합성 장면에 주인공이 나오지 않음
- 장면·캐릭터의 뒤로 늘어진 띠 끝, 남자 소환·용신 장면의 어깨 표식 (부분 수정 필요)
- 대기·용신 장면의 실제 구슬 개수 재확인
- 남녀 정면 기준 이미지, 실제 품띠 사진 4419.jpg (검수용)
- 백업(ZIP 내보내기/가져오기) 미구현 — 기획서상 후순위
